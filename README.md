# Chat Monitor
Cross-platform dashboard for monitoring and managing AI conversations.

Proyecto de investigación de viabilidad y desarrollo de una interfaz privada para supervisar y continuar chats normales de ChatGPT (también dentro de proyectos) desde Windows y iPhone. No sustituye los chats por Work, Codex ni conversaciones de API.

## Inicio
El diseño está aprobado; todavía no hay aplicación ni integración validada.
