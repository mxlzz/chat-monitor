## Contratos verificados en fuente primaria
- [MCP Events](https://developers.openai.com/plugins/build/mcp-events), secciones Before you start, How it works, Advertise event support, Test in ChatGPT: disponible en Work web, Work Cloud de escritorio y dots. Streamable HTTP o MCP 2.0 HTTP. Declarar capability events; implementar events/list, events/subscribe, events/unsubscribe en mismo endpoint autenticado. El host suministra callback y secreto; validar usuario y filtros, verificar callback con desafío firmado, persistir suscripción, expiración y refresco, entregar por HTTPS con firma según Standard Webhooks. Requeridos almacenamiento persistente y HTTPS saliente. Una respuesta HTTP 2xx reconoce recepción, no prueba ejecución. El host procesa asíncronamente y puede agrupar eventos. La especificación incluye una prueba real de suscripción, disparo, respuesta y cancelación. Polling/streaming del contrato de eventos no soportados.
- [Hosting a plugin with ChatGPT Sites](https://help.openai.com/en/articles/20001547-hosting-a-plugin-with-chatgpt-sites): aloja MCP y plugin; propietario debe publicar, luego instalar y conectar. No se localizó confirmación específica de que el runtime Sites permita registrar events y efectuar callback HTTPS firmado con suscripción persistente. Verificar, no inferir. El ensayo anterior de widget tuvo publicación pero no plugin instalable identificado, por lo que esta puerta es material.
- [Scheduled tasks in ChatGPT](https://help.openai.com/en/articles/10291617-scheduled-tasks-in-chatgpt): Work admite tareas disparadas por eventos compatibles de Gmail, Slack y GitHub en planes elegibles (incluye Plus); GitHub se limita a actividad de pull requests según esta guía. Permisos y revisión de trigger/instrucciones; aprobación puede pausar ejecución. Plus: 5 tareas activas según guía actual. No confundir lista de integraciones nativas con el contrato separado de MCP Events para plugins. No se confirma que Site sea fuente nativa de eventos.
- [Cloud Browser](https://help.openai.com/en/articles/20001280-using-cloud-browser-in-chatgpt) y [controles de dots](https://help.openai.com/en/articles/20001554-managing-dots-in-chatgpt-workspaces): navegador documentado para Work Cloud y controlado por disponibilidad/permisos. No se acredita que la sesión del envío manual anterior sea reutilizable en una ejecución activada por eventos ni que la acción de enviar a ChatGPT normal esté permitida desatendidamente. Mantener separado de recepción de evento. No se establece una duración máxima garantizada por ejecución.
